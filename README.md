# 🎬 Mis Películas

Aplicación móvil desarrollada para gestionar y organizar una colección personal de películas de una manera sencilla e intuitiva.

La aplicación permite visualizar películas, consultar información detallada y agregar o editar títulos dentro de la colección.

## 🚀 Instalación

Para ejecutar el proyecto localmente:

1. Clona el repositorio:

```bash
git clone https://github.com/Dxf647/Mispeliculas.git
```

2. Abre el proyecto desde **Android Studio**.

3. Espera a que Gradle sincronice las dependencias del proyecto.

4. Ejecuta la aplicación utilizando un dispositivo Android o un emulador.
